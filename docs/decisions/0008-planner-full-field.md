## 全场版的决策

`ORDER = (spot_07, spot_01, spot_03, spot_02)`；南边两座为 `MANDATE = (spot_07, spot_01)`；L1 完成检查为 `BEFORE_CLIMB = (spot_07, spot_01, spot_02)`；L2 自己半边为 `L2_OURS = (spot_08, spot_05)`。

- `spot_07` 是南边自己的塔，空塔优先吃两地一摞。`spot_01` 是南共享；看清已有两层地、手头有单块天空且自己南塔暂时不用天时，可以先封南共享。
- `spot_03` 是北边自己的塔，不挡 L1 完成检查，接收南边用不上的地和合适的地天摞。`spot_02` 是北共享，在普通供货顺序靠后；对方天空的翻转仍可插队，并非所有情况都最后。
- 北共享已有对方天空时，南边自己的塔能吃红地就先放；人在南边且北边自己的塔吃得下货时，先带货去放，再翻。人已在北边则先翻，避免回来再跑一趟。共享区被挡时跳过。
- 按实际能拿的货找塔：空塔吃两地摞，一层地吃地天摞，两层地吃单块天，不足两层可吃单地。不拆地天摞来凑单块天空。自己的塔被标为被挡时继续按已知状态工作；共享区仍跳过被挡目标。
- 开局只有地天摞、自己空塔吃不下时，可以先拿再往南共享走，在观察点转身检查，减少空手往返。里面单块天不会把外面的完整地天摞从货单里藏掉。
- L1 吃不下当前货时，可先把货送到 L2；所以 `BEFORE_CLIMB` 是 L1 完成检查，不是禁止提前上楼的硬门槛。上楼前先拿货，不空手上台再下来拿。
- 缺某种货就试其他能放的塔。都对不上才等货，写明未完成目标，不因连续等待几次就当作完成。人在 L2 时先试自己半边两塔，再试合适的 L1 目标。
- 当前 `choose()` 的结束动作为 `STOP`，理由是「五色石已被抢走，自己半边两座已封顶，停下」。`MUSTIKA` 名称仍存在，但这版没有实际取放五色石步骤。

更细的原始规则见 `0006`，与当前代码不一致处以本记录和 `8c231d2` 为准。
